# harry-potter-web
Una web interactiva basada en el primer libro de Harry Potter, Harry Potter y la piedra filosofal. Una web enfocada en niños de 8 a 12 años que se han leído el libro por primera vez y han entrado en el mundo mágico. La web estará dedicada a hacer que sientan pertenencia a este mundo, creando su propia historia y superando diferentes pruebas.
